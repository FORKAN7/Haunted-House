# 3D Haunted House

## Chosen Option
Option 2 — 3D Stealth Game: Haunted House.

## Description
A stealth game where the player must escape a haunted house
while avoiding static guards and patrolling ghosts.

## Unity Version
Unity 6000.5.9f1

## How to Run

### Play in a Browser
Open the published game:
[Play Haunted House](https://play.unity.com/en/games/48a67b4a-b20a-4263-9daf-084ed54ab055/3d-game)

Click inside the game window, then use WASD to move.

### Open the Unity Project
1. Download this repository using Code → Download ZIP and extract it,
   or clone the repository.
2. In Unity Hub, select Add project from disk.
3. Select the folder containing Assets, Packages, and ProjectSettings.
4. Open the project using Unity 6000.5.9f1.
5. Open Assets/_3DStealthGame/Scenes/Mine.unity.
6. Press Play.

## Build and Publishing
Platform: Web (WebGL).
The game is published on Unity Play using the link above.

## Controls
W: Move forward
S: Move backward
A: Move left
D: Move right

## Game Objective
Reach the exit without being detected.
Getting caught triggers the losing sequence.

## Bonus Features
None.
