# 3D Haunted House

## Chosen Option
Option 2 — 3D Stealth Game: Haunted House.

## Description
A stealth game where the player must escape a haunted house
while avoiding static guards and patrolling ghosts.

## Unity Version
Unity 6.7

## How to Run
1. Extract the project ZIP if needed.
2. Open Unity Hub and select Add project from disk.
3. Select the folder containing Assets, Packages, and ProjectSettings.
4. Open the Mine scene and press Play.

## Controls
W: Move forward
S: Move backward
A: Move left
D: Move right

## Game Objective
Reach the exit without being detected.
Getting caught triggers the losing sequence.
